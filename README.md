# «Химера»

Камерное приключение со стелсом на выживание по повести «Химера»: 15-летний Артём идёт через светящийся Норильск с одним фильтром противогаза и учится тому, что выживает не тот, кто стреляет, а тот, кто умеет замереть.

Движок — **Godot 4** (2D, вид сбоку). В репозитории две сцены:

- **Пролог** (`scenes/prologue.tscn`, запускается по F5): угасающий бункер, мастерская деда, стена корней у гермодвери и первый выстрел Дефлотатора, туман и маска, ржавая шахта, выход в светящийся город. Свет, тени, силуэты и звук, собранный кодом.
- **Серый полигон «Замри»** (`scenes/main.tscn`): прямоугольник-Артём, слепые симбиоты, шум шагов и дыхания, задержка дыхания, фильтр. Чтобы запустить, открой сцену двойным щелчком в панели «Файловая система» и нажми **F6**.

## Как запустить

1. Скачай Godot 4 (обычную версию, не .NET) с [godotengine.org/download](https://godotengine.org/download). Подойдёт 4.3 или новее. Установка не нужна: распакуй архив и запусти файл Godot.
2. Скачай этот репозиторий: зелёная кнопка **Code → Download ZIP** на GitHub, распакуй.
3. В Godot нажми **Import**, выбери файл `project.godot` в распакованной папке, затем **Import & Edit**. Если Godot спросит про обновление проекта до новой версии — соглашайся.
4. Нажми **F5** (или треугольник «Play» справа вверху). Игра откроется в окне.

## Управление

| Кнопка | Действие |
| --- | --- |
| A / D | идти |
| Shift | бежать |
| Ctrl | красться |
| Пробел (держать) | замри: стоять и не дышать |
| E | взять, надеть маску |
| ЛКМ | импульс Дефлотатора (в сторону мыши) |
| R | сменить фильтр |
| Tab | часы деда: цвет фильтра |
| F1 | числа для проверки |
| Enter | заново (на финальном экране) |

## Где числа

Все числа прототипа лежат в `scripts/balance.gd`, с пояснениями по-русски. Поменял, сохранил (Ctrl+S), запустил заново (F5).

## Файлы

- `scripts/prologue.gd` — Пролог: сюжет, свет, туман, звук, Дефлотатор.
- `scripts/glow_layer.gd` — то, что светится само: корни, бутоны, луч, город.
- `scripts/synth.gd` — звуки, собранные кодом.
- `scripts/main.gd` — серый полигон: уровень, шум, укрытия-сохранения.
- `scripts/player.gd` — Артём.
- `scripts/symbiote.gd` — симбиот.
- `scripts/hud.gd` — экран: маска, часы, подсказки.
- `tests/prologue_tour.gd` — бот проходит Пролог и делает снимки экрана.
- `tests/scenario_test.gd` — бот проходит уровень тремя способами (шагом, бегом, крадучись с замиранием) и печатает итог.
