# Toxic Wasteland

2D action-платформер с элементами метроидвании в мрачном pixel art. Платформа: PC (Windows).

Мир пережил экологическую катастрофу. Герой находит в подвале дневник деда и устройство,
очищающее пространство на 3 метра вокруг, и отправляется искать способ остановить катастрофу.

## Как запустить

1. Установите **Unity Hub** и **Unity 6** (любая версия `6000.x`, например 6000.0 LTS).
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/DeCont94/ToxicWasteland.git
   ```
3. В Unity Hub: **Add → Add project from disk** и выберите папку `ToxicWasteland`.
   Если Hub предложит другую версию Unity, соглашайтесь.
4. При первом открытии Unity может спросить про новый **Input System** — нажмите **Yes** (редактор перезапустится).
5. Сцена `Assets/Scenes/Main.unity` создастся сама. Нажмите **Play** ▶.

Уровень, герой, враги и интерфейс собираются из кода при запуске (`GameBootstrap`),
поэтому руками в сцене ничего настраивать не нужно.

Сборка .exe: меню **Toxic Wasteland → Собрать для Windows (.exe)** → появится `Builds/Windows/ToxicWasteland.exe`.

## Управление (клавиатура + мышь)

| Действие | Клавиша |
|---|---|
| Ходьба | A / D (или стрелки) |
| Прыжок | Пробел / W (держать — выше) |
| Удар арматурой | ЛКМ или J |
| Устройство (держать) | ПКМ или K |
| Сменить режим устройства | Q или колесо мыши (клик) |
| Аптечка | H |
| Говорить / осмотреть / торговать | E |
| Диалоги и магазин | W/S — выбор, Enter/E/ЛКМ — подтвердить, Esc — выйти |

## Что уже есть (демо-глава «Руины города»)

- **Здоровье:** 5 HP на старте (до 10 через прокачку), удар = 1 HP, красная полоска из ячеек слева сверху.
  При уроне герой сжимается, хватается за живот, летят капли крови.
- **Аптечки:** лежат в мире, носить до 3 шт., лечат 1 HP (2 HP после улучшения), анимация перевязки и шуршание.
- **Устройство деда** (радиус 3 м), синяя полоска перезарядки под здоровьем:
  - *Очистка* — световой луч, 1 HP/сек врагам, убирает токсичные лужи и завесы, звук энергии.
  - *Загрязнение* — токсичное облако, оставляет временные лужи с пузырями (2–3 HP врагам).
- **Враги:** мутант (преследует), ползун (быстрый), плевун (стреляет токсином). Сдержанная реакция на урон.
- **Торговец улучшениями** (аптечки, стерильные бинты, +1 к здоровью, батарея устройства). Валюта — лом.
- **Сюжетный NPC Марта** — диалог с 3 вариантами ответа (нейтральный / положительный / отрицательный).
  Рамка выезжает снизу, текст печатается по букве, звук перелистывания.
- **Головоломка:** токсичная завеса → растворить лучом очистки → ударить рычаг → ворота открываются.
- Фонари-чекпоинты, яма с жижей, шторм с молниями, параллакс-руины.

## Где что лежит

```
Assets/Scripts/
  Core/     ввод, генерация пиксель-арта (Art.cs), звуки (Sfx.cs), эффекты, точка входа
  Player/   герой, его статы, устройство очистки/загрязнения
  Enemies/  враги и их снаряды
  World/    уровень (LevelBuilder.cs), сюжетные тексты (Story.cs), NPC, головоломки, камера, фон
  UI/       HUD, диалоги, магазин, вступление
Assets/Editor/  автосоздание сцены и сборка .exe
```

- **Тексты сюжета** — `Assets/Scripts/World/Story.cs` (черновики, их можно свободно переписывать).
- **Арт и звук сейчас временные** — генерируются в коде. Позже заменим на нарисованные спрайты.
- **Пиксельный шрифт:** положите TTF с кириллицей в `Assets/Resources/Fonts/PixelFont.ttf`, и он подхватится автоматически.
